HOW TO ADD A TEAM MEMBER
1. Create a subfolder using the person's full name.
2. Copy TEMPLATE_profile.txt into it and rename it profile.txt.
3. Add photo.jpg / photo.jpeg / photo.png / photo.webp / photo.gif / photo.mp4 / photo.webm.
4. Fill the profile fields.
5. Commit.
The folder name becomes the person's name automatically.
