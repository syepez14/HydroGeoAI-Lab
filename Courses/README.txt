COURSES

Create one folder per course inside /Courses.
The folder name becomes the course title shown on the website.

Example:
Courses/Hyperspectral Remote Sensing/
  course.txt
  image1.jpg
  image2.jpg
  intro.mp4

Recommended course.txt fields:
Type: Course / Workshop / Certificate / Short Course
Topic: Remote Sensing / Hydrology / AI / UAV / etc.
Level: Introductory / Intermediate / Advanced
Format: Online / Hybrid / In-person
Status: Open / Coming Soon / Closed
Start: 2026-11-15
Duration: 12 hours
Price: CLP 120,000
Instructor: Name
Summary: Course description.
Registration: https://...
Link: https://...
Syllabus: https://...
Documentation: https://...
Publications: https://...; https://...

You may add multiple images, GIFs or videos to the same folder. They rotate automatically on the card and can also be opened full screen.
For multiple links in one field, separate URLs with semicolons or put each URL on a new line.
